Foundation

Origin & principles

RackWire began as a single HTML file for planning the cabling of a theatre rig — one document, opened from disk, that made no network request and asked for no account. That constraint turned out to be the product. A planner used in a rack room, a dimmer beach or a loading dock has to work where the signal does not, and a plan that cannot be opened in ten years is not a plan. Everything below follows from holding that line while the tool grew from one stage to three editions.

Offline is the default, not a mode

Every edition opens from a local file and completes its core work with the network unplugged. Features that require a connection are additive and are named as such at the point of use. A release that cannot be exercised on an air-gapped laptop has regressed.

Provenance over plausibility

Any figure a user could sign a load schedule against carries its source. Datasheet values and representative values are visually distinct everywhere they appear, and the tool never silently upgrades one to the other.

The file outlives the vendor

Plans are plain JSON with a documented shape, exportable to CSV without loss of the fields an engineer needs. No format we ship should require RackWire to read it.

System

Colour

The four signal hues are the same tokens the planner uses for its cable domains, so the identity and the running application cannot drift apart. Steel carries structure only and must never be given signal meaning — the full hue↔domain binding, including the two hues added at v1.1, is on page 09. Across any surface the signal hues together cover no more than 10% — the composition reads dark first, colour second.

Practice

Imagery & AI policy

Treatment recipe

Capture at 2× device pixel ratio on the ground background with browser chrome removed. Crop to the feature, never the whole window. No drop shadow, no perspective, no device frame. Corner radius 8px. Annotate with the accent at 2px stroke only.

Generated imagery — permitted

Exploratory concept work and internal moodboards. Abstract textures and geometry where no human, no identifiable artist's style and no third-party mark is depicted.

Generated imagery — prohibited

Any screenshot or depiction of the product. Anything imitating a living artist's style. Depictions of real equipment, venues or people. Any generated asset that ships without disclosure in the asset record.

Practice

Voice & tone

RackWire talks to somebody standing in front of a half-patched rack with a call in forty minutes. It states what is true, names what it does not know, and gets out of the way.

Precise, not pedantic

Give the number, the unit and the source. Do not restate the obvious, do not hedge a value that is measured, and never pad a sentence to sound thorough.

Plain, not folksy

Short declarative sentences in the language an engineer already uses. No exclamation marks, no jokes in error states, no addressing the user as “friend”.

Candid, not alarming

Name the failure and the fix in the same breath. A warning that cannot be acted on should not have been written.

OnboardingBrief and confident. Assume competence; the user has racked gear before.
Analysis warningState the rule, the offending element, and the remedy. No apology.
ErrorWhat failed, what was preserved, what to do next — in that order.
MarketingClaims that survive a datasheet check. Name the ceiling, not “unlimited power”.

Copy rules

Don’t

Oops! Something went wrong 😕

Do

Import failed at line 42: unknown port type “XLR7”.

Don’t

Unlimited devices, infinite possibilities!

Do

Studio plans an unlimited device count. Pro stops at 150.

Don’t

This device might use around 500W

Do

575 W — nominal. Confirm before signing a load schedule.

Don’t

Warning: potential DMX issue detected

Do

Universe 2 is unterminated. Terminate at the last fixture.

Each “don’t” above shipped on a real surface at some point. The pattern behind every rewrite: name the thing, give the number, state the next action. Adjectives that cannot be checked against a datasheet do not appear on any RackWire surface, marketing included.

Components

Practice

Motion

Instant — 120ms

Hover, focus ring, button press, checkbox. Anything acknowledging a pointer that is already on the element. Easing ease-out.

Transition — 220ms

Panel open, inspector slide, tab change, cable dialog. The default for anything moving a region of the interface. Easing cubic-bezier(.2,.8,.2,1).

Deliberate — 400ms

Full-view change and first paint of the canvas. Nothing exceeds 400ms; a plan of 150 devices must never wait on an animation.

Reduced motionUnder prefers-reduced-motion: reduce every duration collapses to 0ms and transforms are removed. Opacity changes may remain. This is mandatory and ships with the first release that has any motion at all
Never animateAnalysis results, punch-list rows, or any measured value. A number that fades in reads as a number still settling
CanvasPan and zoom follow the pointer directly with no easing and no inertia
